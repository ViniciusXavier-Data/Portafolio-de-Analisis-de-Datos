# Portafolio de Análisis de Datos

Repositorio donde documento mi transición profesional hacia el análisis de datos. Aquí publico ejercicios y proyectos de SQL, Excel, estadística y Power BI, con su código, datos públicos y conclusiones.

## Objetivo

Construir un portafolio sólido y conseguir mi primera oportunidad como analista de datos en remoto.

## Estructura

- `01-estadistica`: estadística descriptiva e inferencial
- `02-sql`: consultas y ejercicios
- `03-excel`: análisis y tablas dinámicas
- `04-powerbi`: dashboards y storytelling
- `proyectos`: proyectos completos
